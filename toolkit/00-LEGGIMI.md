# Agenti AI per i contenuti: il toolkit

Materiali del webinar "Agenti AI per i contenuti" della Agents Week di Learnn. Servono a costruire un sistema che porta i tuoi contenuti dai dati alla bozza, con la revisione che resta a te.

## Cosa c'è dentro

| File | A cosa serve | Quando lo usi |
|---|---|---|
| 01-prompt-per-ogni-fase | I prompt da copiare, uno per ogni passaggio: archivio, idee, bozza, correzioni, routine | Durante tutta la costruzione |
| 02-skill-post-linkedin | Una skill da adattare per scrivere post LinkedIn con la tua voce | Dopo aver creato l'archivio dei tuoi post |
| 03-skill-articolo-blog | Una skill da adattare per trasformare un evento, una call o un webinar in un articolo | Quando hai una registrazione o delle note |
| 04-skill-revisione-anti-ai | Le regole per togliere dalle bozze le frasi che suonano scritte da una macchina, in italiano | Su ogni bozza, prima di pubblicarla |
| 05-checklist-revisione-bozza | I controlli da fare su una bozza prima di pubblicarla | Ogni volta che rivedi |
| 06-file-istruzioni-cartella | Il file di istruzioni da mettere nella cartella di lavoro dell'agente | Il primo giorno |

## Da dove partire

1. **Chiedi oggi l'export dei tuoi dati a LinkedIn** (Impostazioni e privacy, Privacy dei dati, Ottieni una copia dei tuoi dati, archivio completo): arriva in circa 24 ore ed è l'unico passo che non dipende da te.
2. **Crea una cartella di lavoro** sul computer, per esempio "contenuti", con dentro tre cartelle: archivio, dati, bozze.
3. **Metti nella cartella il file di istruzioni** (06), adattato a te.
4. **Costruisci l'archivio** dei tuoi post con i prompt A1-A3 del file 01: indice, metriche e regole della tua voce. Se non hai mai pubblicato, parti dai contenuti di altri che ti piacciono e scrivi perché.
5. **Crea la tua prima skill** con il prompt A4, oppure adatta la 02.
6. **Scrivi il primo post** con la skill e correggilo prima di pubblicarlo: le correzioni diventano regole con il prompt D1.
7. **Solo dopo tre o quattro settimane** trasforma il lavoro in una routine con il prompt E1.

Le skill (02, 03, 04) si salvano come file di testo con estensione .md: in Claude Code vanno in .claude/skills/nome-skill/SKILL.md dentro la cartella di lavoro, negli altri strumenti si incollano nelle istruzioni del progetto.

## Funziona anche senza Claude

Il metodo è lo stesso su tutti gli strumenti, cambiano i nomi delle voci:

| Cosa ti serve | Claude | ChatGPT | Gemini | Copilot |
|---|---|---|---|---|
| Collegare le app | Connettori | App collegate | App Google | Dati di Microsoft 365 |
| Istruzioni salvate | Skill e progetti | Progetti e GPT | Gem | Agenti |
| Lavoro che parte da solo | Routine | Attività pianificate | Azioni programmate | Prompt programmati |
| Agente sui file | Claude Code e Cowork | Codex | Strumenti per sviluppatori | Agent Builder |

Se il tuo strumento non legge i file di una cartella, incolla il contenuto dei file nella conversazione o caricali in un progetto.

## Tre regole per le prime settimane

- **Bozze, mai pubblicazioni automatiche.** L'agente prepara, tu pubblichi.
- **Ogni errore diventa una regola** nella skill, con il motivo.
- **Accanto a quanto produce l'agente, misura quanto viene letto.** Un agente che scrive tanto e non viene letto è lavoro sprecato.
