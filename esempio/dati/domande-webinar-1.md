# Domande delle persone al webinar 1 dell'Agents Week

Circa 230 domande di contenuto arrivate in chat durante il webinar del 28 settembre, raggruppate per tema. I conteggi sono approssimati e contano i messaggi, non le persone. Nessun nome: le frasi sono riportate senza chi le ha scritte.

### 2.1 Che differenza c'è: chat vs agente, Cowork vs Code, Claude Code vs Codex, ChatGPT Work vs Codex (~32)

Mi sto perdendo qualcosa?"; "ho l'impressione che fare una richiesta a Claude tramite chatt o agente non cambi la risposta".

- Claude Code vs Codex (~8): "In base a quale criterio scegli di affidare una task a claude code oppure codex?"; "tra claude code e codex non c'è davvero nessuna differenza?"; "Durante la Claude Week hai spiegato VS Code con Claude Code, perchè ora stai usando Codex? è meglio?".
