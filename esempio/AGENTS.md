# Contenuti di Luca Mastella (cartella di esempio del webinar)

Questo file è un esempio compilato del file di istruzioni, nella versione che legge Codex. La versione da compilare con i tuoi dati è `AGENTS.md` nella radice del repository.

## Chi sono e per chi scrivo

Luca, CEO di Learnn. Scrivo su LinkedIn e sul blog per professionisti e piccole aziende che vogliono usare l'AI nel lavoro di tutti i giorni, senza un team tecnico.

## Come è organizzata la cartella

- `archivio/`: `voce.md` (le regole del mio modo di scrivere) e `post-indice.md` (i post più letti, con prima riga e link).
- `dati/`: `domande-webinar-1.md`, le domande arrivate in chat al primo webinar dell'Agents Week.
- `.claude/skills/`: post-linkedin, articolo-blog, revisione-anti-ai. Ogni skill è un file `SKILL.md` dentro la sua cartella.
- `risultati-pronti/`: gli output già generati, da confrontare con i tuoi o da usare se l'agente è lento.
- `bozze/`: tutto quello che scrivi finisce qui, con la data nel nome del file.

## Le skill

Claude Code carica da solo le skill in `.claude/skills/`. Con gli altri strumenti, quando ti chiedo di usare una skill, apri `.claude/skills/<nome>/SKILL.md` e segui quelle istruzioni come se fossero parte di questo file.

## Regole che valgono sempre

1. Scrivi solo bozze. Non pubblicare, non inviare, non programmare niente senza il mio sì.
2. Non inventare numeri, nomi, citazioni o storie. Se ti manca un dato, chiedilo.
3. Per ogni affermazione indica da quale file o link viene.
4. Non modificare e non cancellare i file in `archivio/` e `dati/`.
5. Ogni bozza passa dalla skill `revisione-anti-ai` prima di arrivare a me.
6. Quando ti correggo, chiedimi se la correzione va salvata come regola in una skill.
